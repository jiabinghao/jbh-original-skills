# HTML 视频内容合成

先处理视频内容如何组成，重点是镜头和时间关系。已有成片的单纯渲染或环境修复不必重做分镜。明确尺寸、时长、帧率、文字、音频与素材权限，保留用户指定风格。

## 核对项目实际契约

读取项目版本、入口和现有合成方式，查对应版本的 [官方合成文档](https://github.com/heygen-com/hyperframes/blob/main/docs/concepts/compositions.mdx)与 [CLI 文档](https://github.com/heygen-com/hyperframes/blob/main/docs/developers/cli.mdx)。框架不同版本可能对轨道、时长和动画注册有不同约定；不要将多份文档中的相反规则混用，以项目版本、实际运行与检查结果为准。

## 把分镜变成时间计划

为镜头记录开始、结束、画面、文字、声音及与邻近镜头的关系。统一使用秒描述时间，采样时再按目标帧率转换；约定镜头结束点后是否仍可见，检查边界帧的漏画和双重显示。重叠必须有表达目的，不能只是时间计算失误。

外层合成负责整体尺寸与时间，子场景使用局部时间。嵌套时核对起点偏移、裁剪长度、缩放与音频范围；不要把父时间直接当作每个子场景的时间。媒体原文件长度与画面显示长度分别核对。

## 实现可重复的画面

根据当前框架契约编写 HTML、样式和动画绑定，使用明确、稳定的标识。不同场景命名避免冲突，素材路径按实际入口解析。尺寸、时长和可见窗口必须能被运行时识别；最终规则用该版本的检查工具核实，不凭浏览器中偶然可见判断正确。

同一时间位置应生成同一画面。将随机输入固定，避免动画依赖播放历史或墙钟；字体、图像与异步输入准备好后再采帧。不得照搬第三方主题模板或未授权品牌资产。

## 核验与交付

采样镜头边界、重叠位置、文字密集处和最后有效帧，必要时前后跳转再比较画面。检查音画时序、素材加载与字幕裁剪。交付项目文件、时间计划、预览入口和未验证项；需要成片时才继续渲染并核对输出。此技能不自带框架或云服务，内容编排不自动授权发布。
