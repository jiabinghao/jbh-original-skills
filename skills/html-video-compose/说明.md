# HTML 视频内容合成 · html-video-compose

将分镜和素材组织为可定位的 HTML 视频场景，检查嵌套时间、动画与关键边界画面。

- **建议输入**：分镜、素材权限、项目版本、尺寸、时长、帧率和风格要求。
- **预期输出**：HTML 合成项目、时间计划、预览入口及采样核验记录。
- **能力边界**：需要 HyperFrames 运行环境；关注内容编排，与已有 video-build-flow 的构建渲染侧重点不同。
- **完成依据**：同一时间可重复生成同一画面，镜头边界和音画关系有实际观测，不混用不同版本契约。

## 调用示例

> 请用 $html-video-compose 把三段分镜做成 20 秒的 HTML 视频项目，核对嵌套场景和转场边界。

使用前需要代理平台具备任务相应的文件、开发、浏览器或媒体工具；缺少工具时应说明未完成项。这是独立编写的指令包，不附带参考技能的软件实现。
