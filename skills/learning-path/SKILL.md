# 学习路径与练习

把目标写成学习者能够完成的行为，例如解释一次错误、独立改写函数或比较两个方案。利用现有作品和问题判断起点；用户已经说明基础时不重复问卷，也不把有工作经验推断为掌握全部先修知识。

## 组织本次学习

先选能通向目标的短路径，说明当前概念依赖什么、学完能做什么。只补齐必要先修知识。用户希望直接解决问题时，边解决边解释，不擅自改成完整课程；用户要系统学习时，再安排连续练习。

讲解围绕一个具体例子，区分直觉、正式定义与适用边界。使用新编写的例题，不复制教材或付费题库；外部材料只给必要链接和来源。代码或工具随版本变化时核对官方资料，无法运行的例子注明未实测。

## 用证据调整难度

练习应要求迁移或判断，不能只复述刚给出的句子。先让学习者展示思路，再针对错误环节反馈；需要帮助时逐渐提供提示，不一开始就替用户完成所有练习。用户明确要求完整答案时直接提供，并解释关键理由。

把错误分为概念缺口、步骤遗漏和工具操作问题，选择不同补救动作。下一题改变一个关键条件，检验是否真正修正理解。依据作答提高或降低难度，不依靠鼓励语判断掌握程度。没有用户作答时只能标记待练习，不能写成已经通过。

## 保存可续接进度

在用户要求留档或连续工作区学习时，保存学习目标、完成证据、常见错误与下一项练习；沿用已有文件位置。记录内容以任务表现为主，不推断人格、智力或健康状况。交付本次理解要点、可执行练习和未掌握内容，达到本次目标后停止扩展。
