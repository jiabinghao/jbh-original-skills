# 学习路径与练习 · learning-path

围绕可展示的学习目标安排讲解与练习，根据实际作答调整难度并记录后续学习路径。

- **建议输入**：学习目标、已有基础、可投入时间，以及近期问题或作品。
- **预期输出**：针对性讲解、练习、作答反馈和可续接的进度记录。
- **能力边界**：没有学习者作答时不认定掌握；不会复制教材、付费题库或代替用户完成全部训练。
- **完成依据**：每个练习支持目标行为，反馈针对具体错误，下一步难度依据实际表现调整。

## 调用示例

> 请用 $learning-path 帮我学习 Python 异步任务，先诊断基础，再用小练习逐步确认理解。
