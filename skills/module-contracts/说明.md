# 模块边界与契约设计 · module-contracts

以真实调用场景设计模块接口，明确状态归属、失败语义和恢复路径并比较维护成本。

- **建议输入**：调用者场景、项目约定、状态与副作用、兼容要求。
- **预期输出**：接口契约、正常与恢复调用示例、设计取舍及迁移范围。
- **能力边界**：重点是新边界和接口设计；已有 architecture-tune 侧重维护问题驱动的局部重构。
- **完成依据**：调用者不用了解内部机制即可完成任务，失败恢复有明确语义，兼容成本已说明。
